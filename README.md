# Idle RPG Clicker — Pixelscape

A retro pixel-art incremental clicker RPG. Click to battle dungeon monsters, collect gold, purchase gear upgrades, recruit automated companion heroes, and prestige through tougher encounters.

## Features

- **Active & Idle Gameplay**: Tap manually to deal critical blows or relax as hired companions auto-attack.
- **Progression Loop**: Level up attributes, unlock legendary weapons, collect relics, and advance stage depths.
- **Retro Audio & Visuals**: Chiptune-style sounds, CRT scanline toggles, and animated 8-bit sprites.
- **Offline Progress & Auto-Save**: Saves game state directly to browser `localStorage` to resume your adventure anytime.

## Getting Started

Open `index.html` in any modern web browser or use it on https://jameop1.github.io/idle-rpg-clicker/
